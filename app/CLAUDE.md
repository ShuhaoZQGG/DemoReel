# DemoReel App (SwiftUI)

macOS 14+ SwiftUI application. Requires Xcode 16+, Swift 5.10.

## Build

- `open DemoReel.xcodeproj` then Cmd+R in Xcode
- Project generated by XcodeGen from `project.yml` — edit project.yml, not .pbxproj
- Regenerate project: `xcodegen generate` (from this directory)
- Depends on `core/target/universal/libdemoreel_core.a` — run `../scripts/build-rust.sh` first

## Structure

- `DemoReel/Recording/` — ScreenCaptureKit capture, CGEventTap mouse/keyboard logging, overlay UI
- `DemoReel/Editor/` — Timeline, preview player, style/cursor panels, clip management
- `DemoReel/Export/` — Export sheet UI, NativeExporter calls Rust export functions
- `DemoReel/Shared/AppState.swift` — `@Observable` app-wide state, screen routing
- `DemoReel/Generated/` — Auto-generated UniFFI Swift bindings (do not edit manually)

## Conventions

- State: `@Observable final class` pattern (modern SwiftUI, not ObservableObject)
- One primary type per file, filename matches the type
- Rust calls go through generated bindings in `Generated/DemoReelCore.swift`
- No unit tests — app is tested manually via Xcode
